# Poster Design Skill

Create a clear visual system before making a poster. Choose the production mode by the delivery need; do not let copy safeguards flatten the visual idea.

## 1. Intake

Collect or infer: audience, communication goal, one main promise, approved copy, factual sources, target channel and dimensions, CTA, brand assets, and visual references.

Use `需确认` for missing claims. Do not invent employers, instructors, prices, schedules, testimonials, credentials, results, or brand assets. Treat screenshot text as unverified unless the user supplies or confirms it.

## 2. Production mode

- **Visual exploration** — default for direction drafts. Freely generate the complete visual concept, including expressive typography where it helps test the mood. Generated wording is visual reference only.
- **Hybrid publication** — recommended for external distribution. Generate the visual system, composition, lighting, texture, illustrations, and non-verbal graphics freely. Overlay title, factual copy, dates, digits, CTA, and supplied logo as editable text/assets. Preserve the visual force of the generated base.
- **Fully generated** — use only when the user explicitly accepts that visual-model text can be wrong, or rapid concepting matters more than exact copy.

Chinese, mixed-language text, and small digits can fail in any image-generation workflow, not only image-to-image editing. Never regenerate a supplied logo.

## 3. Design read

Before production, state these five choices briefly:

- communication goal: conversion / outward promotion / explanation
- information density: single-screen / long-form / carousel
- visual tension: restrained / assertive / dramatic
- asset dependence: type-led / supplied assets / generated background
- brand fidelity: supplied profile / inspired palette / neutral

Keep color separate from visual direction. Do not borrow another brand's logo or palette by default.

## 4. Visual directions

- **Clear course** — large title, one promise, compact summary, 3–5 points.
- **Industry momentum** — authoritative title, restrained scene or data texture, a few verified proof points. Avoid fake terminals, fabricated logos, and unsupported big numbers.
- **Editorial premium** — grids, whitespace, refined type, selective warm accents. Avoid generic gold-luxury effects and stacks of cards.
- **High-density explanation** — report-like hierarchy, strong labels, strict columns, consistent dividers; use a long-form layout or carousel rather than shrinking type.

## 5. Build the hierarchy

Use one main promise and 3–5 supporting points on a single-screen poster. For a curriculum, comparison, or more than six meaningful facts, use a long-form layout or carousel.

Long-form course order: compact identity and course-summary strip → audience/outcomes → curriculum → CTA. Keep line height and row padding generous. Do not shrink body type only to retain every paragraph.

## 6. Quality gate

For a concept draft, check visual impact, hierarchy, and brand direction; label generated wording as non-final.

For hybrid publication, compare every publication-critical overlay with the approved copy. Check Chinese glyphs, punctuation, English terms, digits, contrast, clipping, reading order, and mobile readability at 100% size. Keep the editable source with the export.

For fully generated output, state that it is a concept draft rather than verified external material.
