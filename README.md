# Poster Design Skill

A visual-first poster design skill for education, career development, training, consulting, and knowledge products.

## Production modes

- **Visual exploration** — use full image generation to test strong visual directions; any generated wording is reference-only.
- **Hybrid publication** — generate expressive visual layers, then overlay verified title, body copy, dates, numbers, CTA, and supplied logo as real text/assets.
- **Fully generated** — fastest concept path when the text-risk is explicitly acceptable.

## Use with Codex

Copy `skills/poster-design-skill` to `~/.codex/skills/poster-design-skill`.

## Use with Claude Code

Claude Code loads personal skills from `~/.claude/skills/<skill-name>/SKILL.md` and project skills from `.claude/skills/<skill-name>/SKILL.md`.

```bash
cp -R skills/poster-design-skill ~/.claude/skills/
# or, in one project:
cp -R skills/poster-design-skill .claude/skills/
```

The same source is compatible with both tools. See the [Claude Code Skills documentation](https://code.claude.com/docs/skills).

## Contents

`skills/poster-design-skill/` contains the main `SKILL.md`, production workflow, quality gates, brand profile template, design recipes, layout guidance, and DBC sample index.
