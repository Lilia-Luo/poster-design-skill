# Content Intake

Create a copy manifest before visual work.

```text
Audience:
Communication goal:
Main promise (one sentence):
Approved copy (verbatim):
Facts and their source:
Unknown facts (mark 需确认):
Channel and target dimensions:
CTA:
Brand profile or brand assets:
Available visual assets and usage rights:
Production mode: visual exploration / hybrid publication / fully generated
```

Ask one question only when the missing answer changes the factual copy, brand, target dimension, or layout. Otherwise give a neutral proposal.

Treat a screenshot as visual reference, not a reliable copy source. When an image contains small or ambiguous words, transcribe the uncertain fragment as `需确认` and request confirmation before final typesetting.

## Copy manifest rules

- Store each text element separately: logo text, eyebrow, title, subtitle, sections, body, table headers, rows, CTA, notes.
- Preserve user-approved strings verbatim. Do not correct terminology, punctuation, dates, or capitalization without showing the change for approval.
- For hybrid publication, put all publication-critical strings in editable text layers or HTML/SVG text nodes. The generated visual remains free to supply expressive, non-factual typographic texture.
- For visual exploration or fully generated output, treat generated text as visual reference only; ask for confirmation before using it as factual material.
